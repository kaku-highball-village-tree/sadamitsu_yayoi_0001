# python_オフコンデータ_名前挿入

オフコンから出力された「商品マスタ」のCSVファイルから、商品コードと商品名の対応表TSVを作成するPythonプログラムです。

## 対象ファイル

- 入力: ファイル名に `商品マスタ` を含み、拡張子が `.csv` のファイル
- 出力: `商品コード_商品名_対応表.tsv`
- 入力CSVの1行目はヘッダー（列名）とします。
- 抽出列: `商品コ－ド`、`商品名（漢字）`、`商品名（カナ）`
- 出力列: `商品コード`、`商品名（漢字）`、`商品名（カナ）`（この順番）
- 入力CSVの全データ行を元の順番で出力します。値の前後の空白や先頭のゼロは変更しません。

## 動作環境

- Python 3.10以降
- 追加ライブラリのインストールは不要です。
- 入力文字コード: UTF-8（BOMあり・なし）またはCP932（Windowsの日本語CSVで一般的な文字コード）
- 出力文字コード: UTF-8（BOM付き）
- 出力形式: タブ区切り（TSV）、1行目にヘッダー付き

## 使い方

### 1. 自動検索

`product_master_to_tsv.py` を入力CSVと同じフォルダーに配置し、そのフォルダーで次を実行します。

```bat
python product_master_to_tsv.py
```

現在のフォルダーで、ファイル名に「商品マスタ」を含むCSVを探します。候補が複数ある場合は勝手に選ばず、エラーで停止します。

### 2. ファイルを指定

```bat
python product_master_to_tsv.py --input "C:\data\商品マスタ_(20261105_101012).CSV"
```

出力TSVは入力CSVと同じフォルダーに作成されます。同名の出力ファイルが既にあると上書きします。

## 出力例

```text
商品コード<TAB>商品名（漢字）<TAB>商品名（カナ）
80004<TAB>                              <TAB>                    
```

`<TAB>` は実際にはタブ文字です。値が空白のみの場合、元の空白を保持します。

## 注意

- CSVの列順が変わっても、ヘッダー名から必要な列を探します。
- `商品コ－ド` のハイフンの一部の表記ゆれを吸収します。
- 商品コードを数字に変換しないため、先頭ゼロは保持します。
- TSVをExcelで開いた際、Excel側の自動型変換で先頭ゼロが消えることがあります。必要に応じて列の型を「文字列」に指定して読み込んでください。
- 実際のCSVがヘッダーなしの場合は、別途処理の変更が必要です。
